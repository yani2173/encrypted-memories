Help and feedback

Support

Encrypted Memories is community software provided without a support warranty. Clear, privacy-safe reports still help make it better.

Questions and how-to help

Use the Encrypted Memories Wiki for setup, usage, and device-support questions. GitHub Issues are only for reproducible bugs and concrete feature proposals.

Open the Wiki

Before reporting a problem

  1. Install the latest available TestFlight or App Store build.
  2. Check the existing GitHub issues for the same symptom.
  3. Record the app version, build number, Apple device, and OS version.
  4. Use Report a bug in Settings and save the scrubbed support file.
  5. Open a GitHub issue, describe the problem, and attach the reviewed support file.

Open the issue tracker

Keep private data private

Do not post passwords, session data, API keys, private photos, filenames, or account details. Review every diagnostic file before sharing it.

Proton account and service support

This project cannot change a Proton account, subscription, service status, or server-side data. Contact official Proton Support for those requests.

Support development

The app is open source. Optional tips are available in release builds after Apple approves them. You can also sponsor development on GitHub.

Encrypted Memories is not affiliated with or endorsed by Proton AG.
